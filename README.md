Language Translation Tool

A web-based translation tool supporting 20+ languages.

Features
- Multi-language support (English, Hindi, Spanish, French, German, etc.)
- Real-time translation using Google Translate, Microsoft Translator, or MyMemory API
- Copy button for translated text
- Text-to-speech functionality
- Fully responsive and mobile-optimized
- No installation needed - open in browser

How to Use
1. Open `translator.html` in your web browser
2. Enter text in the left box
3. Select source and target languages
4. Click "Translate"
5. Use "Copy" or "Listen" buttons

Technologies
- HTML5, CSS3, JavaScript
- REST APIs (Google Translate, Microsoft Translator, MyMemory)
- Web Speech API for text-to-speech
